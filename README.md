💰 SmartMoneyEveryday

Smart money every day, financial wellness for everyone.

SmartMoneyEveryday is a mobile application designed to help users manage their personal finances efficiently. The app allows users to track expenses, manage multiple accounts, send and request money, and stay within a defined daily spending limit — all in one place.

📱 Overview

Managing money can be difficult without proper tools. SmartMoneyEveryday simplifies financial tracking by giving users full control over their spending habits, helping them make smarter financial decisions daily.

🚀 Features

🔐 User Authentication

Secure user registration and login

Password validation (minimum 6 characters required)

Ability to update user credentials

💸 Expense Tracking

Add expenses with:

Amount

Category (Food, Rent, Electricity, etc.)

Description

Start and end time

Optional image

Real-time updates on spending

📊 Spending Insights

Visual spending breakdown using charts

Easy tracking of financial habits

⚠️ Daily Spending Limit

Set a custom daily limit

Receive warnings when limit is exceeded

Encourages responsible spending

🏦 Account Management

Create and manage multiple accounts:

Main Account

Savings Account

Emergency Account

Set initial balances

Switch between accounts

💰 Transactions

Send money to other users

Request money 

Add transaction references

Choose account for transactions

🎁 Additional Services

Buy airtime (MTN, Vodacom, Cell C, etc.)

Purchase data bundles

Buy vouchers (e.g., Netflix)

⚙️ Profile Management

View and update personal details

Change password securely
